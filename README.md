# 当班油款结算台（加油站班次交接）

交接页即结算台：每笔油款记录**卡号、油品、应收、预授权、支付方式**，未到账金额留在待结区并标明缺额，解决“站长只核销量、挂账次日才发现”的问题。

- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 数据只保存在本机浏览器 `localStorage`（键名 `dfwlfront-7-settlement-v1`），重开页面不丢失。

## 结算规则

1. **确认到账才计收入**：预授权只是银行冻结额度，不计收入；只有“确认到账”登记的金额计入当班收入。
2. **同卡更新原单**：同一卡号存在未结清单据时再次提交，只更新原单，不重复开单，字段差异自动写入改错记录。
3. **未结款随原班责任人移交**：交班只封存班次，未结单据不结转进新班收入；在新班待结区以“移交款”展示，确认到账后仍计入**原下单班次**的收入。
4. **改错留痕**：任何字段改错必须填写原因，旧值、新值、操作人、时间全部保留，可在单据“记录”中查看。
5. **按班次查询**：顶部下拉可重开任意历史班次，查看该班销量、应收、收入、未到账缺额与台账。

## 代码分层（四层分开）

| 文件 | 职责 |
| --- | --- |
| `src/settlement/catalog.ts` | 油款资料：油品挂牌价、班次/支付方式档案、演示数据 |
| `src/settlement/settlement.ts` | 结算判断（纯函数）：到账状态、缺额、缺额说明、班次收入、同卡命中、移交筛选 |
| `src/settlement/storage.ts` | 本机保存：localStorage 读写、开班/交班/提交/到账/改错的落库动作与数据一致性 |
| `src/settlement/useSettlement.ts` | Vue 响应式绑定 |
| `src/App.vue`、`src/components/PaymentCard.vue` | 页面展示与交互，不直接做结算判断 |
