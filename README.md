# 加油站班次交接 · 当班油款结算台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则冒烟测试：`npx esbuild scripts/smoke.ts --bundle --platform=node --format=esm --outfile=/tmp/smoke.mjs && node /tmp/smoke.mjs`

## 业务规则

- **每笔油款资料**：卡号、油品、加油升数、应收、预授权、支付方式、缺额说明。
- **同卡只更新原单**：同一卡号再次提交不新建单，只更新原单字段并自动留痕（旧值→新值）。
- **待结区**：未到账金额 = 应收 − 已确认到账；预授权冻结不等于到账，需人工确认请款结果。
- **确认到账才计收入**：只有在「确认到账」弹窗登记的收款才计入当班收入；交班后次日到账也仍归原班。
- **换班移交**：交接班只结班次，未结单据不挪单、不冲销，随原班责任人移交，接班人可代收确认。
- **改错留痕**：改错必须填原因，逐字段保存旧值/新值、操作人与时间；卡号不可改。
- **重开可查**：数据保存在浏览器 localStorage，可按班次（含已交班）查询结算与单据。

## 分层

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 油款资料领域模型 |
| `src/settlement.ts` | 结算判断（到账/缺额/状态/班次汇总，纯函数） |
| `src/storage.ts` | 本机保存（localStorage 读写、种子数据） |
| `src/store.ts` | 操作编排（提交、确认到账、改错、交接班，写后落盘） |
| `src/components/*` | 页面（录入表单、单据卡、确认到账/改错/交接班弹窗） |
| `src/App.vue` | 当班结算台总装：录入、待结区、班次查询 |

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
